# Numbered menu refusals

These fixtures are edits of known menu shapes. They contain no live pane data.

- `clipped.txt` adds a scroll marker to the frame in `../claude_question_narrow.txt`.
- `narrow_clipped.txt` reflows the same Claude Code 2.1.316 question to about 40 columns and cuts off its top rule and tab row.
- `numbered_text.txt` keeps only the question and numbered text.

The tests also use the complete Claude captures and the scroll marker in `../codex_0.169.0_model_menu.ansi`.
